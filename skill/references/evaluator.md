# 第2層: 見た目の採点(評価者)— 枠のみ

**状態: 枠だけ。運用開始は第2段**(較正セットの作成 = 準備③ の後)。モードO(オペレータの案件)では**納品前に走らせない**。デザイン担当が事後QAとして使う。第1層(`preflight.md`、印刷・可読性のコードチェック)とは別物。

## 1. 役割と入力

執筆側の思考・履歴を見ない別の評価者(モードD ではサブエージェント、事後QA では Claude Project「パンフ評価者」)が、次だけを受け取って採点する。

- 面単位・正立のスクリーンショット(表1 は長辺 1568px で単独。逆さ面は 180°回して正立に)
- 事実だけのブリーフ(案件名・読み手・ゴール行動・載せる内容)
- ルーブリック(下表)と較正例
- パス2 でのみ: `#tone` の中身と、可変ノード一覧(名前+面座標 mm+変えてよい属性)

**`#tone` はパス2まで渡さない**(パス1 は盲検)。

## 2. 手順

0. 採点の前に「プロの AD なら直す点を3つ」を書く
1. G0 欠陥ゲート
2. パス1: R1〜R4 を既定3点から出発して採点。4以上を付けるときは画面上の観察を2つ引用する
3. パス2: `#tone` と可変ノード一覧を開示し、R5 と修正指示
4. チェックリストの該当 ID を列挙

## 3. ルーブリック(計画書 6.5)

| 項目 | 5点 | 3点 | 1点 | 減点トリガー |
|---|---|---|---|---|
| G0 欠陥ゲート(合否) | 生成画像に手指/顔/車両(ハンドル位置・ドア数)/画像内文字の破綻がなく、仮置き文言もない | — | — | 1件でも該当で不合格、再生成指示のみ |
| R1 親しみ・温度 | 顔のある人物が表1ビジュアルの 1/3 以上、地域の暮らしの中でゴール行動をしている。大面積の色が暖かい(寒色系統では「明るく澄んでいる」) | 人物はいるが小さい/汎用的 | 人物なし、白地に箱の羅列、威圧的 | 同一笑顔の AI 定型(−1)/着物・杖・白髪の記号(−1)/視線が CTA と逆(−0.5) |
| R2 行動の明快さ(4未満は不合格) | 5秒で「電話する/LINE 登録する」と言え、電話番号が本文の3倍以上で受付時間付き、QR 2cm 角以上+説明 | CTA が2つ同格で競合 | CTA が埋もれる | 本文・数字への袋文字・影・傾き(−1)/座布団なしの画像上文字(−1)/1面に3メッセージ以上(−1) |
| R3 固有性・非定型(対比評価) | 同一基底案を使った直近2件と並べて一目で別物、固有要素(地域モチーフ、実車、愛称、地名入り見出し)が本文以外に3つ以上 | 固有要素1〜2 | 地名を消せばどこでも使える | チェックリスト該当1件ごと(−0.5)/富士山+桜+鳥居(−1) |
| R4 クラフト | 最大要素が1つで2番目との差が明確、余白が3群以内、角丸・罫線・線幅が揃う | 均一サイズで主役不在 | 密集、端が揃わない | 効果2種以上(−1)/角丸不統一(−0.5)/1〜2mm のズレ3箇所以上(−1) |
| R5 統一感(パス2) | すべてのイラストが同一描法、色は `#tone` の役割どおり、見出し書体は1種 | 描法の違う素材1点 | 描法の混在、面ごとに書体が違う | 持ち込み混在1点ごと(−0.5)/`provenance: default` の項目は照合対象外 |

合格: R2 ≥ 4、R3 ≥ 3、加重平均(R1 .25 / R2 .25 / R3 .25 / R4 .15 / R5 .10)≥ 4.0。

修正指示の形(最大3件):

```json
{"node":"#人物","face":"表1","severity":"must|should","targets":"R1","instruction":"…","handoff":false}
```

固定区分(寸法・折り・本文の書体/サイズ・固定ブロック)への要求は `handoff: true` にして引き渡しリストへ回す(スキルは直さない)。

## 4. 較正セット(第2段で作る)

- (a) プロ制作 = 5点の例: `参照` ページ(6:2)の実案件の完成品から選ぶ(完成見本ページは空)
- (b) 失敗例 = 1〜2点: 改修前の制作物・テストページから選ぶ

- 置き場所・一覧・Project の設定手順: 未定(第2段でこの節を埋める)

## 5. モードD のループ制御(5.2、参考)

各周の開始時にフレームを `_r1/_r2/_r3` として複製し、組版 → 第1層 → スクショ → 第2層 → 上位3件修正、を最大3周。採用は最終周(前周比で加重平均が 0.3 以上下がったら前周)。早期停止: ピンポン/固定層要求/平坦化(Δ<0.2)/装飾インフレ/第1層 Fail が減らない。周・スコア・解決済みリストは `#state` に保存する。
