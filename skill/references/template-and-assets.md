### 複製の手順

1. get_metadataで上表のノードIDを確認する(IDが変わっていたら名前で探し直す)
2. 対象フレームをcloneし、`制作物`ページへ移す(`const p = figma.root.children.find(x => x.name === "制作物"); await p.loadAsync(); p.appendChild(clone);`)→既存フレームと重ならない空き位置に配置→「案件名_表紙/中面/スポット表_日付」に変更する
3. マスター本体・参照ページは編集しない

### 差し替えの約束事

- 差し替え対象は、テンプレートで**空欄になっているテキスト**と画像プレースホルダ。文言・画像を入れるだけにし、フォント・サイズ・罫線・レイアウトは変えない
- 未確定の電話番号・日付等は「(仮)」を付けて入れる

## カラーの適用(メイン1色相の濃淡モデル)

テンプレートの配色は「メイン色の濃トーン(見出し帯・枠・強調)+淡トーン(背景面)+紙の白」で構成されている。案件の色に替える手順:

1. ヒアリングで確認したメイン色を濃トーンに充てる。アクセントは指定があった場合のみ置換
2. 淡トーンはメイン色から自動導出する(同色相で明度を上げ彩度を落とす。目安: HSLでL+25〜35・S−20〜30)
3. 置換は2グループ一括で行う: 下表の濃トーン群→新メイン色、淡トーン群→新淡色。**黒系(#000000 / #231815 / #1D1715 = 文字・イラスト線)と白・グレーは触らない**

| 系統 | 濃トーン | 淡トーン | 備考 |
|---|---|---|---|
| あいとま系 | #EB6EA5 | #F6BED1, #FFD8E3 | |
| 那智勝浦系 | #1B98D0 | #76C1E3 | アクセント黄 #FAEF50 は指定時のみ置換 |
| 登別系 | #D7835F | (白ベース・淡なし) | |
| MITT系 | #254F99, #143747 | #258FC2ほか | **ブランド固定色。原則色替えしない** |
| 乗降スポット表 | #EB6EA5, #DE4891 | — | 複製後、案件の濃色に合わせる |

4. 置換後にget_screenshotで反映漏れを目視確認する(表と微妙に違う近似色の直塗りが残っていたら個別に直す)
5. **画像化された装飾・イラスト(IMAGE fill)には色置換が効かない。** SVGでの自作差し替えは品質が保てないため行わない。基本はそのまま残し、案件カラーと合わず色味の調整が必要な箇所は、Step 5の引き渡し時に「イラストの色味調整」として残タスクに含めて報告する(色味の調整は作業者が手作業で行う運用)

### カラー未定時の提案

1. 題材・地域のイメージから2〜3案を選定する(例: 海沿いの町→青系、温泉地→暖色系、公的な信頼感→紺系)
2. `制作物`ページの隅に、案ごとの濃淡チップ+案名を並べたカラー見本フレームを生成する
3. スクリーンショットで見せて選んでもらう。RGB値の口頭提示はしない(非エンジニアには選べない)
4. 決定後、不採用案の見本フレームは削除する

## イラスト・写真の受け渡し

利用者が商用利用可のサイトで選び、Figmaに取り込む。案内は平易な文で伝える。

**基本フロー(確実に動く):**

1. 利用者が素材をダウンロードし、`素材`ページに**案件名のグループ(またはフレーム)を作ってその中に**置く
2. 利用者からそのグループのURLを受け取る。URLの`node-id`(例: `?node-id=12-34` → ノードID `12:34`)でグループを特定する。URLがもらえない場合はグループ名(案件名)を聞き、名前で特定する
3. **対象はそのグループ内の画像のみ。素材ページ全体を走査しない**(過去案件の素材が溜まっており、どれを使うか判別できないため)。グループ内の画像を数えて点数を報告し、**全点の配置先を決めた計画**(どのイラストを紙面のどこに使うか)を提示する
4. 計画に沿って、cloneでパンフの所定位置に複製・配置・リサイズする。グループ内の元画像は残す(再利用のため)

案内文の例: 「選んだイラストを、Figmaの『素材』ページに今回の案件名でグループ(枠)を作って、その中にドラッグ&ドロップで入れてください。入れ終わったら、そのグループを選択して右クリック→『選択部分へのリンクをコピー』でリンクをコピーして、ここに貼ってください」

**全点使用の原則:** 案件グループに入っているイラストは、利用者が選んで持ってきた素材なので**すべて配置するのが前提**。イラスト置き場が足りなければ、ブロックの脇・背景・余白のワンポイントとして追加配置してよい(可読性基準は守る)。紙面に収まらない・トーンが合わない等で使い残す場合は、勝手に間引かず「〇〇は△△の理由で外しますが良いですか」と確認を取る。

**チャットに画像が添付された場合:** upload_assetsでの取り込みを試し、失敗したら基本フローを案内する。

**既存テンプレートのイラスト流用(オプション):** 利用者の指示があれば、テンプレート・参照ページにある既存イラストをcloneして配置してよい(マスター・参照の原本は変更しない)。案件カラーと色味が合わない場合もClaudeは色をいじらず配置のみ行い、色味調整は残タスクとして引き渡す。

### ライセンス確認(素材を受け取るたび)

どのサイトの素材かを確認し、以下を利用者と確認する。最終判断はせず「規約のこの点を確認してください」と指摘に留める。

- 商用利用の可否 / クレジット表記の要否(必要なら発行者情報欄へ) / 加工の可否 / 1制作物あたりの点数制限
- 出所不明の画像は配布物に使わない

## 入稿データの厳守(最重要)

このファイルの制作物はそのまま**印刷入稿用データ**になる。寸法がズレると折り畳んだ際に折り山の印刷がズレるため:

- 基準寸法(参照ページの本データと同一): 冊子の表紙・中面 = **1691×2392**(那智勝浦系の中面のみ横型 **2392×1691**)、乗降スポット表 = **794×1123**
- 折り位置は高さ(横型は幅)の**ちょうど1/2**(縦型なら y=1196)
- **フレームのresize・面境界の移動は絶対にしない。** 複製は原寸のまま行い、複製直後にwidth/heightが基準寸法と一致することを確認する
- 折り位置をまたぐ要素・接する要素の位置は動かさない。動かす必要が出たら手作業に引き渡す
- 背景・裁ち落とし要素は塗り足し線まで伸ばし、文字は仕上がり端・折り位置から余裕を持って内側に置く
- 書き出しはPDF。入稿先の指定を最優先する
