# パンフレットのデザインルール(Figma版)

読むかどうかは手に取った0.5秒で決まる。勝負はキャッチコピーと第一印象。

## 情報設計

- キャッチコピーはベネフィットで書く(「最新設備導入」でなく「待ち時間が半分に」)。最も目立つ位置・最大サイズに置く
- ジャンプ率を高く。見出しと本文のサイズ差を大きく付ける
- CTAは動詞で書く(「今すぐお電話ください」)。可能なら期限・特典を付ける
- 視線誘導: 横書きはZ型(左上にキャッチ、右下にCTA・連絡先)、縦書きはN型(右上起点)
- 電話番号・価格など最重要の数字は赤系で本文の3〜4倍に
- 1面1メッセージ。見出しは主張文(「現状分析」でなく「電話受付で月40件を取りこぼしている」)。強調は1面1〜2箇所まで
- 数字には出所を付ける。根拠がなければ「推計」と明示する

## デザイン表現 — 「正しいが素っ気ない」を避ける

配布物のデフォルトは親しみ型。整理型(白背景+単色の箱の羅列)は行政通知・BtoB技術資料など限られた場面のみ。

| 表現 | Figmaでのやり方 |
|---|---|
| 暖色の背景 | フレームfillを薄いクリーム・薄橙に。上部に空・雲、下部に街並みシルエット(createNodeFromSvgで自作可) |
| 袋文字(白フチ+影) | テキストにstroke(白・太め・OUTSIDE)+Drop Shadow |
| 傾いた帯 | 帯フレームのrotationを-3〜-5度 |
| タイトルの多色化 | 文字範囲ごとに色設定(2〜3色まで) |
| バッジ・吹き出し・リボン | テンプレートの部品を流用。なければcreateNodeFromSvgで自作 |

- 人物イラストを少なくとも1体入れる(顔のあるイラストは紙面の親しみと注目を大きく上げるため)。ターゲット層と同属性で、ゴール行動をしている姿(電話をかける人等)が理想
- 人物以外のイラストも積極的に入れる。各訴求ブロックのワンポイントイラスト、電話・LINE・地図・時計などの定番アイコン(「電話の場合」の文字より受話器アイコン+文字のほうが視認が速い)。素材ページに使えるイラストがあれば優先的に活用する
- イラストを増やしても可読性基準は下回らない。窮屈になったら文字情報でなくイラスト以外の装飾から削る
- 囲みの形に変化を付ける。ただし1紙面の図形パターンは3種類まで
- 装飾は見出し・背景・囲みに限定し、本文はシンプルに保つ

## 可読性基準(絶対に下回らない)

| 項目 | 一般向け | 高齢者・初見向け |
|---|---|---|
| 本文サイズ | 10.5〜12pt | 12〜14pt |
| 行間 | 1.6〜1.8倍 | 1.6〜1.8倍 |
| コントラスト比 | 4.5:1以上 | 7:1以上 |

- 色だけで意味を区別しない(色+形・ラベルで二重に)。赤×緑、青×紫は判別しにくい
- 細い明朝の小サイズ・白抜きは避ける。写真の上に直接文字を載せず、半透明の座布団を敷く

## 高齢者・初見の読み手への配慮

- 専門用語を言い換える(「QRコード」→「四角い模様(カメラで読み取れます)」)
- 手順は番号付き・1手順1文
- 電話番号はQRと同格以上のサイズで市外局番から。受付時間を併記する
- QRコードは2cm角以上+周囲に余白。読み取ると何が開くかを説明する

## 情報を削る優先順位

1. 削らない: キャッチ / 誰向けか / CTA / 連絡先 / 発行者情報
2. 削れる: 詳細仕様・料金全パターン / 沿革の長文 / 2つ目以降の訴求
3. QRで別媒体へ: 詳細料金 / 事例集 / 申込フォーム

迷ったら「ゴール行動に寄与するか」だけで判定する。

## 書いてはいけないもの

- 根拠のない実績・効果の数字(「導入企業500社」等を創作しない)
- 存在しない事例・お客様の声
- 誇大表現(「業界No.1」「絶対」等)。根拠資料の有無を確認してから使う
