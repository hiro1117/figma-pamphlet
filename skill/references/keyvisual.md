# キービジュアル・ライブラリ(デザイン担当 = モードD 向け)

表紙の絵(キービジュアル)は、デザイン担当が先に作って素材ページにライブラリとして置き、オペレータは番号で選ぶだけにする。このファイルはデザイン担当が Claude Code + Figma MCP で使う手順書。**オペレータの案件(モードO)では読まなくてよい。** 生成・加工のスクリプトはリポジトリ `figma-pamphlet` の `scripts/library/` にあり、配布物(このスキル)には含まない。

## 1. ライブラリの2層

| 層 | 単位 | 中身 | 素材ページの置き場 |
|---|---|---|---|
| 基底キービジュアル | 系統(あいとま/那智勝浦/登別/MITT) | **背景と前景を分けて持つ**。背景 = 空・稜線1本・道・地面(人物・車両・名所は描かない)、前景 = 人物2点・車両1点の切り抜き(実 alpha の PNG) | `ライブラリ/<系統名>`(番号ラベル `ラベル:NN <系統名>`、素材 `NNa-K 役割 \| <生成id>`、非表示ロックの `#tone`) |
| 地域レイヤー | 案件 | `#地域モチーフ` 1点(実在の山・川・名所のシルエット/簡略画、不透明、キー抜き済み)+ 台帳 | `案件/<案件名>`(`#地域モチーフ <名所> \| <生成id>`、`ラベル:<案件名>`、`#台帳`) |

v0(2026-09-27 確定)は各系統 K2 向け1案(描法 = 抽象グラフィック `abst`)。ノード id・imageHash・実効 dpi はリポジトリ `docs/library/library-v0.json`。

スキルは Step 1.5 で `案件/<案件名>` に `#地域モチーフ` があるかを確かめ、**無ければオペレータの作業を止める**(ゲート)。したがって「次に着手する地域」の連絡を共有チャンネルで受けたら、その案件の地域モチーフを先に用意する。

## 2. 運用の手順(5.1)

1. **着手地域の確認**: 共有チャンネル(Slack など)で案件名・地域・名所候補を受け取る
2. **地域モチーフの生成**: 案件ごとに1点。背景と同じ系統の描法・色に合わせる。横長(地平線帯 580×170px 程度)で、単色背景(#00FF00)で生成 → キー抜き
3. **基底案の生成**(新しい系統・描法が要るときだけ): 背景と前景を分けて生成する(下記プロンプト構造)
4. **仕上げ**: 背景はキー抜きしない(情景のまま CROP で使う)。前景はキー抜き(`scripts/library/keyout.py`: 外周から連結したキー色領域をフラッドフィルで透明化+内部の穴のキー色も透明+1px 収縮)。キー色は #00FF00(系統パレットに緑相が無いため)。マスターは 2K(K2 枠 580px に置いて実効 400dpi 超 ≥ 200)
5. **投入**: `upload_assets`(Claude Code 限定。Claude web からは画像の POST ができない)→ `use_figma` でライブラリ/案件グループへ移動・命名・`#tone` 同梱。素材ページの既存グループ(旧案件)は触らない
6. **トーンの言語化**: 採用した基底案ごとに tone.json(tone/3)を書き、グループ内の `#tone`(非表示・ロック、Noto Sans JP Regular 8px)に保存。画像に見えるものだけを書き、見えないものは `provenance: "default"` で既定値から埋める
7. **台帳**: 生成1回ごとにモデル名・経路・日時・プロンプト全文を記録(リポジトリ `docs/library/ledger.csv` と、地域モチーフは `案件/<案件名>` の `#台帳`)
8. **事後QA**: 納品後の制作物を第2層(`evaluator.md`)で採点し、指摘をテンプレ・変換表・ライブラリへ戻す
9. **締め**: `_未確認` で終わった案件の確認、`#config` の更新(版・pipeline)、入稿済みラッパーを `入稿済み` ページへ移す

## 3. プロンプト構造

1. 役割: 地域交通の高齢者向けパンフレットを手がけるアートディレクター
2. 案件: サービスの性格・読み手(70代中心と家族)・ゴール行動(LINE 登録、電話は補助)。**地域名は地域モチーフのときだけ渡す**(基底案には渡さない)
3. 必須要素: 背景側 = 汎用の里山または街並み、空、道(人物・車両・名所は描かない)。前景側(別生成) = 顔のある人物(読み手と同属性、電話をかける/乗車する姿、記号化しない)、乗合タクシー
4. 描法(tone-spec、2026-09-27 決定): **フラット1種**、抽象グラフィック(大きな単純形の組み合わせ、影・グラデ・質感なし)。手描き風は不採用
5. 制約: 画像比率はヒーロー枠に合わせる(K2 = 102:125 は Gemini に無いので **4:5** で生成し Figma の CROP で合わせる)、文字を描かない、写実・3D 調禁止、メーカーロゴ・看板・偽 QR・電話番号らしい数字禁止、着物・杖・白髪だけの高齢者記号化禁止、富士山+桜+鳥居の混合禁止、紫→青グラデ禁止
6. 参照(自社権利物のみ): レイアウトマスク(幾何図形のみ、リポジトリ `docs/library/masks/`)、系統の色チップ。**テンプレ・完成見本・参照ページのスクショやその切り出しは渡さない**(出所未記録のイラストを含むため)
7. 出力: 2K PNG

前景の固定仕様: 人物の肌色は全系統 #F5CEC1。車両は4系統共通の JPN タクシー型(屋根も白、行灯とストライプは系統のアクセント色、運転手・乗客なし、左側面(スライドドア側)が見える向き、右ハンドル)。

## 4. 面表とヒーロー枠(組み込み側の前提)

- A3・6面、k = 5.69 px/mm。表紙面は表紙フレームの右上1面(x 1127.3〜1691、y 0〜1196)
- 表紙の構図は B.1 v2(2026-09-28)から **K2B_panel**(白パネルの中に タイトル → ヒーロー → CTA、ヒーローは裁ち落としなし)。ヒーロー枠 `#キービジュアル` は系統ごとの横長: あいとま 488×398 / 那智勝浦 488×329 / 登別 488×354 / MITT 488×500(比率 0.98〜1.48)。座標は `#config` の `presets.K2B_panel.by_family`
- 背景は縦長の 2K でも幅で合わせて上下を切れば使える(実効 531dpi)。作り直すときは系統の比率に近い Gemini の横長比率(あいとま 5:4 / 那智勝浦 3:2 / 登別 4:3 / MITT 1:1)で生成する(レイアウトマスクは リポジトリ `docs/library/masks/K2B-mask-*`)
- 地域モチーフの帯は 488×143(ヒーロー内の地平線付近。人物・車両より背面)
- 前景の配置規則と枠の座標: `template-and-assets.md`「表紙面の枠」「表紙の絵の配置規則」
- 実効 dpi = 画像 px ÷ 配置 px × 144.6(k × 25.4)。フラット ≥ 200、写真 ≥ 300

## 5. フォントマッピング(tone.json → Figma)

tone.json の `typography.headline.family` は許可リスト内の **Figma 上のファミリ名**で書く(`template-and-assets.md`「フォント許可リスト」)。

| tone.json に書く名前 | Figma で読み込む名前 / スタイル | 備考 |
|---|---|---|
| Zen Maru Gothic / Black | `Zen Maru Gothic` / `Black` | H1(太丸ゴ横組み2色)の既定 |
| M PLUS Rounded 1c / ExtraBold | `Rounded Mplus 1c` / `ExtraBold` | 名前が違う。`M PLUS Rounded 1c` では読めない |
| M PLUS Rounded 1c / Bold | `Rounded Mplus 1c Bold` / `Bold` | Bold だけ別ファミリ名 |
| Noto Sans JP / Black | `Noto Sans JP` / `Black` | 見出しのフォールバック、電話番号(`typography.numerals`) |
| BIZ UDPGothic / Regular・Bold | `BIZ UDPGothic` | 本文のフォールバック |

見出し書体が読み込めないときは Noto Sans JP Black に落とす(スタイルタイルのスクリプトは `headFallback: true` を返す)。

## 6. 正規化の規則(tone.json を書くとき)

- `main` は白と `ground` の両方に 4.5:1 以上(白文字を載せる/見出しの2色目に使うため)。`main_tint` は淡色群の置換先
- `cta` は `ground`・白の両方に 7:1 以上
- `ground` は網点の下限(5%)以上
- MITT 系は `meta.locked.brand_palette: true`(`main` / `main_tint` はテンプレ値で固定)
- `signature_element` は1つ(v0 は4系統とも `none`)
- 保存先は `#tone` の非表示テキスト(FrameNode の description は書けない・setPluginData は使えない)

## 7. ライセンス

- 生成経路は Gemini API 有料枠または Google AI Pro(v0 の背景・人物はアプリ経由)。可視透かし付きの画像(無料アプリ)は配布物に使わない(`#案_透かし有` で区別)
- ソコスト・ちょうどいいイラスト・unDraw などのフリー素材は**生成 AI の参照に絶対に渡さない**
- 生成AIの使用可否はヒアリングで確認し、書面(メール可)で同意を得る
