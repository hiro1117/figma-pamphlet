# ライブラリ v0 の描法(トーン)仕様 — 2026-09-27 Hiro 決定

出典: テンプレ表紙 3 系統(18:2 あいとま / 21:2 登別 / 24:2 MITT)のスクショを目視して言語化。Hiro が「既存テンプレにあるようなデザイン、手描き風は不採用」と決定。
この仕様は tone.json の `illustration.style` と、生成プロンプトの「因子: 描法」の唯一の出典。

## 決定
- 描法は **フラット 1 種のみ**(手描き風は不採用。理由: 同じ面の利用シーン人物・アイコンと描法が混ざる、印刷で淡いにじみが荒れる、キー抜きのエッジが汚い)
- あいとま / 那智勝浦 / 登別 = **細い均一線**(`thin`)。MITT = **線なし**(`noline`、現テンプレ準拠)
- 4K マスターは作らず **2K(1856×2304)をマスター**にする(K2 枠 580px に置いて実効 463dpi ≥ 200)

## 軸ごとの値

| 軸 | 値 | 備考 |
|---|---|---|
| 線 | thin: 均一な細い輪郭線、色 #231815、太さ ≈ 0.5mm(印刷寸法、2K 画像で約 5px)/ noline: 輪郭線なし | テンプレのイラスト線画は #1D1715 / #231815 |
| 色数 | 系統色 2 段(濃・淡)+ 紙白 + 肌色 + 黒(線)。差し色は足さない | MITT は 紺 #254F99 / 青 #258FC2 / 濃 #143747 / 黄 #FAEF50 / 白 |
| 影 | なし(落ち影もハイライトも無し) | |
| グラデーション・質感 | なし(空も平坦な 1 色) | |
| 背景の密度 | 余白の多い情景: 空 + 単純な稜線 1 本 + 道 + 淡色の地面。民家・木は小さく数個まで | 稜線は画像上端から約 60% |
| 顔 | 目・口を線で描く簡略化した顔(点目可)。表情あり | 記号化(白髪・杖・着物)は禁止 |
| 人物の体型 | 頭身 6〜7 の自然な比率、服は今の普段着 | |
| 車両 | 白いワゴン、右ハンドル、窓は系統の淡色、ドアに系統色の細いライン 1 本、エンブレム・文字なし | |

## tone.json への写像(illustration.style)
```json
{"rendering": "flat_vector_thin_outline", "outline_mm": 0.5, "shading": "none", "background": "transparent"}
```
MITT は `"rendering": "flat_vector_no_outline", "outline_mm": 0`。
