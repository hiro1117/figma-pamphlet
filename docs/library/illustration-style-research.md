# 人物イラストの系統調査 — 参照ページの実物と、没にした生成の比較(2026-09-27)

目的: 「AI が描いた、リアル寄りの質感」を避け、参照ページ(6:2)にある**人が描いた**人物イラストの系統に寄せる指示文を作る。
調査は Figma の `参照` ページを読み取り専用でスクショして目視した(生成 AI には一切渡していない。以下は言語化のみ)。

## 1. 参照ページの人物イラストの系統(あいとま表紙202608 / 那智勝浦表紙 / 登別表紙 / MITT LP / 単体素材 老夫婦・通院・家族)

系統名(仮): **「ゆるい線画のビジネスイラスト」**。日本のフリー素材サイトや自治体広報でよく見る、簡略化した線画+単色ベタの人物。

| 観点 | 参照の実物 | 補足 |
|---|---|---|
| 頭身 | **4.5〜5 頭身**。頭が大きく手足は細く短い | 大人も子どもも同じ比率感 |
| 顔 | 輪郭は丸。**目は黒い点 2 つ**(白目・まつげ・ハイライト・二重なし)。鼻は無いか小さな線。口は短い線 1 本。眉は細い線か省略。頬紅・しわ・ほうれい線なし | 表情は口の弧だけで作る |
| 髪 | **1 色のベタ塗りの塊**。毛束・毛流れ・ツヤなし。色は茶・黒・紺・黄など(老夫婦の男性は青髪!)。年齢は髪色より服装・姿勢で出す | 白髪や杖は「あってもよい」が主役ではない |
| 手・体 | 手は指を描かない丸い塊(ミトン)。首・関節・筋肉の描き込みなし | |
| 服 | 1 色のベタ+輪郭線。しわ線ゼロ〜2 本。柄・ロゴなし | 1 人あたり色 4〜5 色(肌・髪・上・下・靴) |
| 線 | **均一な細い黒線(#231815)、閉じた輪郭、強弱なし** | MITT LP は線なしのベタ塗り版(同じ顔の作り) |
| 塗り | 均一。影・ハイライト・グラデーション・質感なし | |
| 密度 | ピクトグラムより少し豊か、アニメ・劇画よりずっと単純 | 情報量が少ないので小さく置いても読める |
| 車両(登別表紙) | 箱型のワゴンを数本の線で。窓 1 色、タイヤ黒丸、細部は最小 | 生成した車両はこれよりはるかに描き込みが多い |

## 2. 没にした生成の系統と、なぜ「AI っぽい」か

| 案 | 系統 | AI っぽさの正体 |
|---|---|---|
| hand(水彩+色鉛筆) | 絵本風の手描き | 紙の質感・にじみ・写実的な光。テンプレのフラット絵柄と混ざる |
| flat(太線) | 海外ストック系ベクター/デジタルコミック調 | 6.5〜7 頭身、白目のある目、鼻筋、毛束のある髪、服のしわ、ワントーン影。「きれいすぎる」仕上げ |
| thin(細線) | 日本の広告向けデジタルイラスト | 頭身・目・鼻・髪・しわ・柄シャツ・靴の描き込みが写実寄り。線はアンチエイリアスで柔らかく、強弱がつく。顔に頬の赤みや目のハイライト |

共通する「AI らしいリアル寄り質感」の要素(= 禁止リスト):
1. 6 頭身以上の写実的な体型 2. 白目・まつげ・ハイライト・二重のある目 3. 鼻筋・小鼻 4. 頬の赤み・しわ・ほうれい線 5. 毛束・毛流れ・ツヤのある髪 6. 服のしわ・柄・ボタン・縫い目 7. 指の描き分け 8. 影・ハイライト・グラデーション 9. 線の強弱・柔らかいアンチエイリアス 10. ストックイラスト特有の「薄くきれいな」仕上げ、アニメ・劇画・3D 調

指示文の反省: 前回までは「顔をはっきり描き、目・口の表情があること」「髪型・体格・服に個性を持たせる」と書いたため、モデルが**描き込みを増やす方向**に解釈した。今回は「何を描かないか」を具体的に列挙し、頭身・目・髪・手・服の作りを 1 つずつ指定する。

## 3. 新しい指示(描法 `yuru` / MITT は `yuru_noline`)

`scripts/library/gen_candidates.py` の `STYLES["yuru"]` と `person_prompt` / `vehicle_prompt` に反映済み(dry-run で `docs/library/prompts/*-yuru-*.txt` に出力)。要点:

- 頭身 4.5〜5、丸い顔、点目、鼻なし、口は線 1 本、眉は省略可
- 髪は 1 色の塊、手はミトン、服は 1 色+線、しわ・柄なし、1 人 5 色以内
- 均一な細い黒線・閉じた輪郭・ベタ塗り・影なし
- 「ピクトグラムより少し豊か、アニメより大幅に単純」という位置づけを明記
- 禁止リスト(上の 10 項目)を明記
- 参照画像は**自作のスタイル見本**(`docs/library/masks/style-tile-person.png`、PIL で描いた幾何図形だけの人物図。頭身・点目・ミトン手・単色ベタの「作り」を示す)+色チップ。参照ページのイラストは渡さない

## 4. 進め方の提案(費用)

- 描法が大きく変わるので、まず 1 図(あいとま 人物 01)を Pro 2K で 1 回、または Flash 1K で 2〜3 案作って当たりを確認してから展開する
- 車両も同じ描法で作り直す(参照の登別表紙の車がその水準)
