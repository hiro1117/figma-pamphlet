## 系統別の枠と Gemini の比率(CROP で切れる量)

Gemini 3 Pro Image の横長比率は 1:1 / 5:4 / 4:3 / 3:2 / 16:9 / 21:9。枠比率に最も近いものを使い、Figma 側は `scaleMode: CROP` で枠を満たす(縦横比を保つ imageTransform を枠と画像の比率から計算)。

| 系統 | ヒーロー枠 px(表紙面ローカル) | 枠比率 | Gemini 比率 | CROP で切れる側 | 切れる量 |
|---|---|---|---|---|---|
| あいとま | (1169−1127.3, 172) 488×398 | 1.226 | 5:4 (1.25) | 左右 | 1.9% |
| 那智勝浦 | (1169−1127.3, 241) 488×329 | 1.483 | 3:2 (1.5) | 左右 | 1.1% |
| 登別 | (1165−1127.3, 217) 488×354 | 1.379 | 4:3 (1.333) | 上下 | 3.3% |
| MITT | (1169−1127.3, 200) 488×500 | 0.976 | 1:1 (1.0) | 左右 | 2.4% |

既存のライブラリ背景(縦長 2K、1792×2400、比率 0.747)をこの枠に置く場合は幅で合わせ、上下を大きく切る(表示されるのは縦の 30〜43%)。稜線が枠に入るよう `imageTransform` の縦オフセットを tone.json の `horizon_ratio` から決める。再生成は H(a) で枠が確定してから(上の比率で)。

## 凡例(色)

- 白 `#FFFFFF`: 白パネルとヒーロー枠(絵が入る領域。枠は細線で囲む)
- 極薄灰 `#EBEBEB` の横帯: 地域モチーフ帯(`#config` の motif 枠、高さ 143px ≈ 25mm)。基底案ではここを単純な稜線にとどめる
- 薄灰 `#D7D7D7`: 人物(左)と車両(右)の想定位置(FIT で置く)
- 灰 `#A0A0A0`: 面の地色(文字ゾーン外)。濃灰 `#6E6E6E`: タイトルゾーン(ヒーロー上)と CTA ゾーン(ヒーロー下)
- 薄灰 `#C8C8C8`: 塗り足し域(上 3mm・右 3mm)。細線: 仕上がり線・折り線
