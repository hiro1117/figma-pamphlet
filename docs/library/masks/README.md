# レイアウトマスク(生成 AI の参照用・幾何図形のみ)

生成: `.venv/bin/python scripts/library/make_masks.py`。数値の出典は `docs/prep/physical-size.md`。
テンプレ・完成見本・参照ページのスクショや既存イラストは**一切含まない**(白/灰の矩形だけ)。PNG に文字は描かない。

| ファイル | 範囲 | 用途 |
|---|---|---|
| `K2-mask-face.png` | 表紙面 99×210mm + 上/右 3mm 塗り足し = 102×213mm(10px/mm) | K2 の全体像。ヒーロー枠と下情報域の関係を示す |
| `K2-mask-hero.png` | ヒーロー枠 + 塗り足し = 102×125mm(比率 0.816 ≈ 102:125) | 基底案(背景)生成の参照。生成画像はこの範囲に相当 |
| `K1-mask-face.png` | 全面ビジュアル(102×213mm) | 第2段の K1 向け(任意) |
| `chips-<系統>.png` | 系統の色チップ(`docs/prep/colors.md` の濃/淡/紙白/文字色) | 色帯域の参照 |

## 凡例(色)

- 白 `#FFFFFF`: 絵が入る領域(ヒーロー枠)
- 薄灰 `#C8C8C8`: 塗り足し域(上 3mm・右 3mm、断裁で消える。重要要素を置かない)
- 灰 `#A0A0A0`: 下情報域(K2 = 表紙面の下約 42%。文字ゾーン。絵を入れない)
- 濃灰 `#6E6E6E`: タイトルゾーン(左寄せ、幅 70%)/ CTA ゾーン(右下)。折り線側(左・下)は 8mm 空ける
- 極薄灰 `#EBEBEB` の横帯: 地平線帯(ヒーロー上端から約 60%、±6mm)。基底案ではここを単純な稜線にとどめ、後から `#地域モチーフ` で覆う
- 細線: 仕上がり線(上・右)と折り線(左・下)、ヒーロー枠の下辺

## 幾何(mm、表紙面の仕上がり左上を原点、右・下が正)

- ヒーロー枠: x 0〜99, y 0〜122(表紙面の 58.1%)。塗り足し込み: x 0〜102, y −3〜122 → 102×125mm = Figma 上 580×711px(k=5.69)
- 下情報域: y 122〜210(88mm)。タイトル: x 8〜77, y 130〜168。CTA: x 40〜96, y 172〜202
- 地平線帯: ヒーロー上端(塗り足し込み)から 60% = y ≈ 72(±6)

## Gemini の比率との対応

Gemini 3 Pro Image の対応比率に 102:125(0.816)は無いため **4:5(0.800)** で生成し、Figma 側で `scaleMode: CROP` で枠に合わせる(上下を約 2% 切る)。K1 向けは 9:16(0.5625)で生成し左右を切る(第2段)。
