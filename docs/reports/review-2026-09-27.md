## CONFIG の決定(第1段の既定値)
| キー | 決定 | 理由 |
|---|---|---|

| `PHONE_RATIO` | **Fail < 2.0、Warn < 3.0** | 現行の電話 46〜75px。3.0 は第2段でテンプレ側の電話を大きくして到達させる(評価者 R2 の「3倍」はそのまま) |

| TEL/LINE ラベル | 数字列だけを `phone`(7:1)。`TEL` `℡` `LINE` などの短いラベルは `label` として **4.5:1** | ラベルは見出し相当 |

| MITT 系本文 15px | **系統別オーバーライド** `PT_BY_FAMILY.MITT = { body: 7.5 }`(Fail 線を現状値に。Warn は 12pt のまま) | 第2段で MITT テンプレの本文を上げるまでの暫定。MITT 系が今後も新規案件で使われるかは Hiro に確認 |
