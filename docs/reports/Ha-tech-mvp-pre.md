1. **欠落フォントのフォールバックを変換表に入れる**: テンプレに Source Han Sans JP(本文・料金表・STEP 等 20 件超)・ADS-piccolo(サブコピー)・Baloo Paaji(電話・TEL/LINE ラベル)が残り、use_figma 環境には無い。`hasMissingFont` のノードには `characters` を書けない。規則: 本文系 = Source Han Sans JP → **Noto Sans JP 同ウェイト**(Medium/Bold)、見出し系 = headline_preset の書体、数字 = numerals の書体。`setRangeFontName` はフォント欠落ノードにも効く(新フォントをロードしてから)。置換は流し込みの前に行う
2. **流し込み手順に「明示改行を外す → 箱幅で折り返し → 高さを測る → 折り線との距離を確認」を入れる**: 案件原稿の改行は別の箱幅向けで、そのままだと 1 語だけの行や折り線越え(利用上の注意が y=1196 ちょうど)が出た。長文の注記は改行を外し、短い見出し・STEP は改行位置を組み直す。箱の高さは流し込み後に一時 clone で HEIGHT 計測(B.1 v2 の申し送りと同じ)
3. **回転ノードで `textAutoResize` を本体上で切り替えない**: 180° の面の中のノード(と 180° フレーム直下のノード)で WIDTH_AND_HEIGHT → NONE と切り替えると位置が 22〜38px ずれた(電話番号 2 か所)。寸法の計測は必ず一時 clone で行い、本体は `resize()` と `relativeTransform` だけで動かす(回転ノードの resize は原点固定で、フレーム座標では負方向に伸びる)
4. **palette.cta の適用先に「白文字を載せた main 色の面」を足す**: 電話予約パネル(`装飾:電話予約枠`)は main 色の面に白文字 → main #B5557F だと 4.6:1 で P4 Fail。cta #6F344E で 9.2:1。規則: 「白文字が載る main 色の塗り面は cta に」。名前 `#CTA:パネル` 以外にも該当があるので、テンプレ側で `#CTA:パネル` 等の名前を付けるのが確実
5. **accent_decor → `#バッジ` は v2 テンプレと衝突**: tone は `#バッジ` = #1B98D0(青)だが、B.1 v2 で Hiro が「まずは登録!」をピンクに変えている。MVP は Hiro の判断を優先して main 色のままにした。D.2 から `accent_decor → #バッジ` を外すか、「テンプレのバッジ色が main 群なら置換しない」とする
6. **headline_preset の対象範囲を明記**: 「`#見出し`系」は表紙のサブコピーだけか、サービス紹介面のキャッチ・利用シーン見出し(Rounded Mplus 1c ExtraBold)も含むのか。MVP は表紙のサブコピーだけに当てた。two_tone の `apply_to: service_name` は、v2 の表紙にサービス名テキストが無い(ロゴ画像)ので発動しない
7. **CROP の imageTransform と crop_focus**: 式は B.1 v2 のとおりで問題なし(f=0.609、ty=0.1955)。crop_focus=person_and_vehicle の平行移動量は今回 0(中央)で足りた。地平線(horizon_ratio 0.54)はヒーロー内 y≈397 に来てモチーフ帯と整合
8. **空のプレースホルダは非表示にする**: 案件に素材が無い `#事業者ロゴ置き場` `#ロゴ置き場` と付随ラベル「×」、見本ピン(`装飾:地図ピン(サンプル一式)`・`#地図ピン見本`)、`サンプル:地図スクリーンショット`。変換表に「素材の無い `#…置き場` と `サンプル:` `装飾:…(サンプル一式)` は hidden」を入れる
9. **案件ブランド色と系統 tone の衝突**: くらぶちはロゴ・改修前とも緑系、tone はピンク。系統選択(Step 1.5/1.7)の時点で「案件の既存色」と「系統 tone」がずれていたら確認を出す(または tone の palette を案件色で上書きする選択肢)

### 7.2 Step 5(ラッパー D.3)の修正点

1. **塗り足しは ground 一色でなく「端の色の延長」**: ラッパーの塗り=端の色の多数派、例外区間は背面の塗り足し矩形。区間は書き出し画像の外周から 8〜12px 内側を走査して取れる(今回は Python で実施)。Figma 内だけで完結させるなら、フレーム直下の面背景ノード(`装飾:背景…`)の bbox と色から計算する
2. **P1 にラッパー寸法を入れる**(§3.3)。今回の実測: rescale 後 858.9×1207.9pt、中身 841.9×1190.9pt
3. **中身を変えたらラッパーは作り直し**: ラッパーは clone なので制作物を直しても追従しない(中面で 1 回作り直した)。Step 5 は「最後の preflight の後に作る」を明記。名前 `案件名_表紙_書き出し_日付` はそのまま使えた
