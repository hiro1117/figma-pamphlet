## 5. 想定と違った点

- **GROUP の bbox は非表示の子を含まない**: 24:2 の 面:表紙面(右上) は人物群を非表示にした時点で高さ 1216 → 1196 になった(#車両写真置き場 の h235 縮小は保険として実施)
- **`node.query()` の selector に日本語が使えない**(`Invalid selector: unexpected character (0xe3)`)。名前で探すときは `findOne` を使う
- `get_screenshot` は塗り足しノードを含めた bbox(1708×2409)を返す。等倍で撮るには maxDimension 2409 が要る。18:2 は回転しているので塗り足しが画像の左・下側に付く
- 20:2 の `#車両` は固定ロゴ(表紙中央 1370〜1457, 565〜646)を避けて y350〜560 に置いた(D-4)。他 3 系統は y440〜640
- preflight は origin/main の cbd0a51 版で走らせた。E の CONFIG 改訂版(Warn・折り線種別)がコミットされたら同じ 5 フレームで再実行すると Fail 数はかなり減る見込み(P6 の x=563.7 またぎ → Warn、注記 18px → Pass、電話倍率 2.0 → Pass)

## 6. 差し替え時の手順(Hiro 確認後)

1. テンプレートページ 0:1 の原本 4 フレームを退避(名前に `_旧` を付けるか `参照` ページへ)し、作業用ページの clone 4 つを 0:1 へ移す(`page.appendChild`、x/y は原本と同じ)
2. `#config`(2057:2)を 0:1 直下へ移す
3. `docs/prep/template-refit-inventory.json` を新 id で再採取し、`skill/references/template-and-assets.md` のノード id 表を更新
4. 差し替え後に preflight を再実行して表4側のダイジェストが一致することを確認
