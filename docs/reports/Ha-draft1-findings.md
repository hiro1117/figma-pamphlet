# H(a) 先行版 draft1 の所見(2026-09-27、Hiro 評価「結構ゴミ」)

対象: 作業用ページのくらぶち MVP 表紙 draft1(あいとま系 2053:3 の clone + ライブラリ v0 + くらぶち文言)。スクショ `docs/reports/Ha-shots/01-mvp-cover-sheet-draft1.png`、`02-cover-face-before-vs-draft1.png`。

## 指摘(Hiro)と原因

| 指摘 | 見えている現象 | 原因 |
|---|---|---|
| キービジュアル枠と表紙背景2の枠の不一致 | ヒーローは全幅 580px(裁ち落とし)、その下の白パネルは左右 42px 内側の 488px。下半分にピンクの縁が出て、上下で端が揃わない | B.1 がヒーローを既存の白パネル構成の上に差し込んだだけで、パネル側を組み直していない |
| ロゴ位置の不自然・中央の空白 | 約 260px 角のロゴが白パネル時代の位置のままヒーロー中央を占め、人物は左端・車両は右端(C の layout_rule)で中央はロゴだけ | ロゴ・人物・車両の配置を別々に決め、合成で確かめていない |
| ロゴとタイトルの被り | 「移動のお悩み解決します」がロゴ上端に隠れる | 同上。タイトル帯の領域がヒーロー内に確保されていない |
| 注記とタイトルの被り | 上端の発行者情報(白 17px)がタイトル・ヒーローに接し、下端では「(事前登録制)」と新設の `#AI表記` が重なる | 注記・AI表記の専用領域が無く、折返し時の高さを見込んでいない |

## 根本原因

B.1 の方針「既存要素は最小限の処置で残し、タイトル・ロゴはヒーローの上に重ねる」(`B1-cover-refit-design.md` §94)。既存表紙は「色背景+白パネル+中央ロゴ」の構図で組まれており、ヒーローを挟んでも要素の位置関係が K2 用になっていない。加えて、B.1 の設計レビューは空のプレースホルダ、C の検証フレームはタイトル・ロゴなしで行っており、実文言+実素材の合成を確かめる工程が H まで無かった。

## 結論

- H(a) 先行版は draft1 で中断。B.1 を「K2 用に表紙面を組み直す」B.1 v2 としてやり直す(`docs/briefs/B1v2-cover-relayout.md`)
- 以後、テンプレ改修の確認は必ず実文言+実素材を入れた合成で行う
- D 後半(Step 3・Step 5)は B.1 v2 → H 再実行の後
