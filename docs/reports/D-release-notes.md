# figma-pamphlet スキル 2026-10 リリースノート

パッケージ: `dist/figma-pamphlet_2026-10.skill`(`scripts/package.sh 2026-10`)。配布は Hiro(Claude Team 組織スキル)。前版 2026-08-20。

## 変わること(オペレータの操作)

- 色見本を選ぶ代わりに、**表紙の系統 → 絵の見本を番号で選ぶ**(折り方を1行で確認)。選んだ理由を一言
- 着手前に、素材ページの `案件/<案件名>` に**地域の絵(`#地域モチーフ`)があるかをスキルが確かめる**。無ければ「準備待ち」で止まる(共有チャンネルでデザイン担当に依頼)
- **スタイルタイル**(色・見出し・電話・絵の縮小を1枚にまとめた見本)を見て「はい」
- 組版・チェック・自動修正・書き出し用の枠づくりはスキルが行い、結果は **○/✗/△ の要約**だけ。✗ が残れば PDF 名の末尾に `_未確認`
- オペレータの画面外の操作は「ロゴ・QR・地図・写真を素材ページに入れる(あれば)」と「PDF の Export」だけ。Export の手順は完了報告に毎回出る
- 生成AIの絵が使えない案件、または `#config` の `pipeline: off` のときは 2026-08-20 の手順で動く

## 既知の制限

- 書式が途中で変わる枠(一部赤字など)は文言を入れず引き渡し
- 箱を伸ばしたときの下の要素との重なり、自動幅の題字と右隣の要素の重なりは自動では見ない(スクショ確認と P3-b)
- 書き出し用の枠の塗り足しは面の箱で近似。端が写真・グラデーションなら手作業
- 中面のスポット一覧は流し込まない(案件ごとに構造が違う。第2段 B.2)
- 第2層(見た目の採点)は枠のみ。オペレータの案件では動かない
- 印刷会社の要件(PDF/X・フォントの Type 3・トンボ)は未確認(決定後に確認)
- 環境に無いフォント(Source Han Sans JP・ADS-piccolo・Hiragino)は Noto Sans JP 等に置き換わる(見た目が少し変わる)
