### C-2. 「親の枠」の決め方(P3-b)

1. 候補 = フレーム内の可視ノードのうち、描画順で TEXT より後ろ(idx が小さい)にあり、可視の fill か stroke を持つ **軸平行の RECTANGLE / FRAME / COMPONENT / INSTANCE**。VECTOR / BOOLEAN_OPERATION は名前が `P3B_VECTOR_PANEL`(パネル|枠|囲み|panel)に一致するときだけ bbox で近似して候補にする
2. 除外 = 最前面の fill が IMAGE、名前または**祖先の名前**が `P3B_EXCLUDE_PANEL`(置き場|イラスト|画像|写真|ロゴ|QR|illust)に一致、祖先に BOOLEAN_OPERATION がある(図形の部品)。画像や絵は文字の容れ物ではないため
3. 候補のうち、TEXT の字面の **`P3B_OVERLAP`(50%)以上を覆い**、字面より面積が大きいものを集め、**面積最小**(最も内側の枠)を「親の枠」にする
4. 枠の内側 = bbox から stroke ぶんを差し引く(INSIDE は strokeWeight、CENTER は半分、OUTSIDE は 0)
5. 字面が枠の内側を `P3B_TOL_PX`(2px)より越えていれば Fail(方向と px、枠の名前を出力)。加えてフレーム(シート)の外に出ていれば「シート外」として Fail
6. 親の枠が見つからない TEXT(背景の上に直接置かれた見出し等)はシート外の判定だけ行う

限界: 枠を bbox で見るため、角丸の大きい枠や斜めの枠では甘くなる。`装飾:背景(サービス紹介面)` のような **名前に「枠/パネル」を含まない VECTOR の白パネル**は候補にならない(名前を `パネル` を含むものに変えるか `P3B_VECTOR_PANEL` に追加すれば拾える)。テキストが 2 つの枠に半分ずつ乗る構図は最小面積の方に寄せる。
