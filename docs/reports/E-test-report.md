- **フレームの回転(あいとま系 180°、デモ表紙の親グループ −180°)による誤りは無し**。absoluteBoundingBox で計算し、設計座標に戻して出力している(x=563.7 は 180° フレームでも「サービス紹介面の中央」を指す)

### P4 コントラスト — Manual 63 件の主因は「背景」グループの波形 VECTOR
- 表紙では `背景` グループの `Vector`(装飾の波・面塗り)が TEXT の下にあり、矩形背景と TEXT の間に挟まる。色の下地が分からないため Manual にしている(誤 Fail を避ける設計)。あずま表紙は対象 26 件中 18 件が Manual
- Fail 25 件はおおむね妥当: 白文字 on 濃色ボタン 5:1(#2E7D5B)・3.4:1(#D96B4D)、#666666 の注記 on 白 5.7:1、#分類見出し 白 on 緑 #1FA64A 3.2:1、`TEL` ラベル #D96B4D on #D9D9D9 2.4:1、デモ中面の #サービス名 #35618E on #D96B4C 1.9:1

- 見逃し: `other` 役割(バッジ・無名ラベル・料金の数字)は対象外(`CONTRAST.other: null`)。グラデ・半透明・部分的な重なりは Manual 止まり

### P2 文字サイズ — 86 件、ほぼ「12pt/10pt 基準に対する本物の未達」
- 注記 16〜18px(8〜9pt)が全系統で 10pt=20px に届かない(#料金n注記 18px、#受付時間 18px、※注記 16px)。**現行テンプレの注記標準は 18px = 9pt** なので、`PT.note` を 10 のままにすると新版テンプレでも常に Fail する
- 制作物ページの 2026-08 版(くらぶち・くろほね・あずま)は本文 18〜22px(9〜11pt)で、本文 12pt にも届かない(旧世代の複製。テンプレ現行の本文は 24〜26px で合格)
- 白抜き 12pt 規則が `料金ラベル_大人 22px`・`中学生以上 12px`・`#事業名 18px`・`#受付時間 18px` に当たる。役割に関係なく白抜きに適用しているため、バッジや料金の補足まで拾う(仕様どおりだが件数が増える)
- v3 で無名 TEXT を「30 字以上 → body」に推定するようにした結果、くろほね表紙で 4→11 件に増えた(15〜22px の説明文、これは本物)
- `#電話受付時間`(MITT 系・くろほね)は接頭辞 `#電話` で phone になっていたので例外を追加し note に戻した(`ROLE_PREFIX_EXCEPT`)
