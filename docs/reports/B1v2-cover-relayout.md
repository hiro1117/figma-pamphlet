## 3. 作り方で分かったこと(D 後半・変換表 D.2 への申し送り)

- **CROP の `imageTransform` は必ず比率から計算する**: 枠比率 rn=w/h、画像比率 ri=iw/ih。rn>ri なら `[[1,0,0],[0,f,(1−f)/2]]`(f=ri/rn)、rn<ri なら `[[f,0,(1−f)/2],[0,1,0]]`(f=rn/ri)。identity のままだと枠に引き伸ばされる(draft1 は 0.816 の枠に 0.747 の絵を 9% 横伸ばししていた)。`crop_focus` は平行移動成分で動かす
- **電話番号の箱は 420 幅**(13 桁)。テンプレの 374 では 2 行に折れる。実施時にテンプレ側を 420 に直す
- **注記・発行者情報は折り返しを見込む**: 「※倉渕地区…(事前登録制)」は 486 幅で 2 行(箱 44、行送り 110%)。発行者情報は 486 幅だと URL 行が 4 行目に折れるので、明示改行 4 行(箱 76)にした。スキルの Step 3 でも「箱の高さは文言を入れた後に HEIGHT で測って確定する」手順が要る
- 欠落フォント(ADS-piccolo)のサブコピーでも `strokes` は付けられる(案C の白フチ)。`characters` は触れない
- `node.query()` の selector に日本語は使えない(`findOne` を使う)。GROUP の x/y はフレームローカルでそのまま指定できる(180° 回転フレームでも)
- 3 案とも「ロゴを小さく」しているので、`#サービスロゴ置き場` の枠サイズは案ごとに変わる。tone.json の `composition.title` に `logo_px` を持たせる候補
