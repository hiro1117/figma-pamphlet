### 改修で意味タグ化する際の観察(推定を含む)

- `#〜本文` `#〜注記` `#〜見出し` `#電話番号〜` `#QR置き場` という命名は既にほぼ一貫しており、名前の後方一致(`本文$`・`注記$`・`見出し$`・`^#電話番号`・`^#QR置き場`)で機械的に拾える。例外: 18:2/20:2/21:2 の `#0:00-0:00`(運行時間、名前が値そのもの)、18:2 の `#利用上の注意`(注記だが名前に「注記」なし)、47:2 の `#※乗降場所の病院・施設・店舗への`(名前が文言)、`#〇〇地区の乗降場所`。
- 固定ラベル(`ラベル:`)・固定見出し(`見出し:`)・バッジ(`装飾:STEPnバッジ・見出し` 配下の STEP/01〜04/事前登録…)は `#` なしで、現行ルール上は触らない対象。CTA文言「ご登録・ご予約は LINEまたはお電話で」もここに含まれる(置換したいなら `#CTA` 化が必要)。
- 電話番号は Baloo Paaji Regular(欧文フォント、Google Fonts に存在)で 43〜75px、問い合わせ先の電話番号は Noto Sans JP Bold 50px。MITT系だけ Noto Sans JP Bold 24〜26px と小さい。
- 混在フォント(mixed)を持つTEXT: 598:6 / 625:17 / 629:12 / 629:13 / 629:17 / 625:25 / 625:26 / 629:34 / 21:73 / 48:497(3色)。`characters` 全置換すると先頭セグメントのスタイルに揃う点に注意。
- textAutoResize: 1行の `#` テキストは WIDTH_AND_HEIGHT(自動幅)、複数行本文は NONE(固定サイズ箱)が多い(凡例10と一致)。NONE の本文に長文を入れると箱からあふれる(48:2 の #サービス名 95px も NONE 476×60)。
