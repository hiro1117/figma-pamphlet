# 色の実測(colors.md)

計測: 各テンプレートフレームの全子孫について、可視ノード(祖先に非表示がないもの)の SOLID fill(非TEXT)/SOLID stroke/TEXT fill を hex(+不透明度%)で集計。`#E6E6E6` fill + `#999999` 破線 stroke は `#〇〇置き場` プレースホルダ(全フレーム共通)。`#1D1715`/`#231815` はイラスト線画・黒系。

## 2. 系統別の「メイン濃トーン / 淡トーン / 紙の白 / 文字色」推定

| 系統 | メイン濃トーン(見出し・帯・枠) | 淡トーン(背景面) | 紙の白 | 文字色(黒系) | その他の固定色 | 現行スキル表との差 |
|---|---|---|---|---|---|---|
| あいとま | **#EB6EA5**(fill35+stroke19+text22) | **#F6BED1**(58, 中面frame fill) / #FFD8E3(6) / **#F4AEC1**(表紙frame fill・×ラベル) | #FFFFFF | #000000(本文・注記)/ #231815(中面の写真番号) | 中面の分類色 #1E5DBA・#D81B60・#1FA64A、スポット表 #DE4891/#DD468F | ほぼ一致。#F4AEC1 が淡トーン群から漏れている |
| 那智勝浦 | **#1B98D0**(fill40+stroke67+text21) | **#76C1E3**(59) | #FFFFFF | #000000 / #231815(STEP見出し4) / #1A2966(中面の電話番号) | アクセント黄 #FAEF50@62、赤 #FFA1A1 1 | 一致(#FAEF50 は不透明度62%付き) |
| 登別 | **#D7835F**(fill72、中面frame fill) | (淡なし)クリーム #F9F2DC 2・黄 #FFF9B3 4 | #FFFFFF | #000000 / **#513A1E**(茶: リード文・電話番号・ポイント名25件) | 番号バッジ赤 #E60012 20・#C30E23、LINE緑 #3CA754 | #513A1E(茶)が第2の濃色として文字・strokeに多用(色替え時の扱い要判断) |
| MITT | **#254F99**(69) / #143747(61) / #258FC2(61) | #F9F27F・#FAEF50(黄帯)、#FCF9C6、#F1F9FC | #FFFFFF | **#231815**(本文)/ **#404040**(注記) | 地図ピン #FF5252/#FA4E4C、更新日赤 #E60012 | 一致(ブランド固定)。本文黒が #231815、注記が #404040 |
| 乗降スポット表 | #EB6EA5 / #DE4891 | – | #FFFFFF | #000000 | – | 一致 |

- 「黒系」実測: 純黒 #000000 が あいとま/那智勝浦/登別 の本文・注記・電話番号、#231815 が MITT の本文とイラスト線画・那智勝浦STEP見出し・番号バッジ、#1D1715 はイラスト線画(表紙3種)、#404040 は MITT 注記、#513A1E は登別の茶文字。現行スキルの「触らない黒系(#000000/#231815/#1D1715)」に **#404040 と #513A1E(登別)** を加える必要がある(推定)。
- 那智勝浦(20:2)・登別(21:2)の表紙フレーム fill が あいとま系のピンク(#F4AEC1)のまま残っている(背景RECTで隠れている)。一括色置換で `#F4AEC1→淡色` を当てるとフレームfillも変わる(無害だが、背景RECTを消すとピンクが出る)。
