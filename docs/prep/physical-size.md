# 物理サイズと折り(2026-09-26 Hiro確認)

- シートは **A3(297×420mm)**。Figmaの作業寸法 1691×2392px がこれに当たる(2392/1691 = √2)
- 折り: **横半分に折ってから巻き三つ折り** → 片面は 3列×2段 = 6面、1面 = 563.7×1196px = **99×210mm(DL)**
- 折り線(px): 縦 x=563.7 / 1127.3、横 y=1196
- 表紙面(表1)= 表紙フレームの右上1面(左辺・下辺が折り線、上辺・右辺が仕上がり端)
- あいとま/那智勝浦/登別: 下段を180°回転(逆さ面)で組む。MITT: 下段正立(6面とも同じ向き)
- px換算: **k = 1691/297 = 5.69 px/mm**、1pt = 2.01px。3mm = 17px、8mm = 46px、12pt = 24px、10pt = 20px、6pt = 12px、2cm = 114px
- 乗降スポット表(794×1123px)はA4想定で k = 3.78
- 入稿: 作業フレーム → 3mm塗り足し付きラッパー 1725.2×2426.2px → rescale(0.497865 = 841.89/1691) → 858.9×1207.9pt = **303×426mm**
- 現行本文サイズの再評価: 24〜26px = **11.9〜12.9pt**(計画の12pt基準をほぼ満たす)。MITT 15px = 7.5pt(要判断)。注記13〜22px = 6.5〜11pt
- 表紙ヒーロー(K2)は表紙面の上55〜60%: 約563.7×(658〜718)px + 上・右3mm塗り足し → 画像比率 ≈ 102:125 = 0.82:1(やや縦長)。K1(全面)は 102:213 ≈ 0.48:1

以前の計画書(v5まで)は「A4を二つ折りしたA5面、k=8.05」を前提にしていたため誤り。計画書 v5.1 で訂正済み。
