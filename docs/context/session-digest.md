## 見つかった技術的制約(実装で必ず考慮)

- Figma Plugin API(use_figma): FrameNode に `description` は書けない(COMPONENT 専用、throw)。`setPluginData` は禁止 → 状態は非表示テキストノード `#tone` `#state` `#config` に持つ
- use_figma は返り値 20KB、コード 50,000 字、ページ切替は1呼び出し1回。`figma.root.findAll` は使わず制作物フレーム起点で1回だけ走査。フォントは `loadFontAsync` を先に全ロード。`figma.mixed` はセグメント単位
- `imageTransform` は `scaleMode:'CROP'` でしか効かない。Figma は 4096px 超の画像を自動縮小。PDF 書き出しは 1px = 1pt・1x のみ(→ 塗り足し付きラッパーを `rescale(0.497865)` して 303×426mm で書き出す)
- Claude web(モードO)からは `upload_assets` の URL に POST できない → 画像投入はモードD(Claude Code)限定。Gemini 系は真の alpha を出さない → 切り出しは単色背景でキー抜き
- あいとま表紙 18:2 は**フレーム自体が180°回転**して置かれ、複製にも引き継がれる → 幾何は absoluteBoundingBox で扱う。表4 の正立スクショは面グループを撮って180°回転
- 乗降スポット表 28:178 は 794×1123 のノードを rotation 90 で横置き(A4 想定 k=3.78)
- テンプレには既存の命名規約(凡例フレーム 599:2)がある: `#`=差し替え可、接頭辞 面:/ブロック:/行:/装飾:/ラベル:/見出し:/イラスト:/固定画像:/サンプル:/ガイド:。新しい `#` 命名はこれに合わせる
- `#〇〇置き場` プレースホルダは73件(#E6E6E6 + #999999 破線)。IMAGE fill は表紙4フレームのみ(imageHash 33種)
- Figma MCP から `figma.root.name` は "Document" しか返らない(タイトルは API で確認不可)。fileKey で識別する
- 印刷会社は未定 → 入稿の既定値(2ファイル・sRGB・トンボなし)で進め、決定後に P24・6.4 を確認
