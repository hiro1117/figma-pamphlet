# 指示書 C: キービジュアル・ライブラリ v0(Nano Banana Pro)

## 目的
オペレータが番号で選ぶだけで表紙が決まるように、系統ごとの「基底キービジュアル」と切り出し素材、各基底案の tone.json 最小版を作り、複製ファイルの `素材` ページにライブラリとして置く。加えて、くらぶちモック用の地域モチーフ1点。生成は Gemini API(gemini-3-pro-image = Nano Banana Pro、有料枠)。API キーは Hiro が用意(`.env`、コミット禁止)。

## 先に読むもの(順番)
1. `CLAUDE.md`, `docs/PLAN.md`
2. `docs/prep/physical-size.md`(ヒーロー比率)、`docs/prep/colors.md`(系統ごとの濃/淡/紙白)、`docs/prep/face-table.md`
3. `docs/plan/plan-v5.1.md` の 5.1(生成手順・プロンプト構造・採用後・投入)、6.1(2層ライブラリ・ヒーローの層構造)、6.2(tone.json v3 と正規化規則)、6.6(ライセンス早見表・AI表記)、C 章
4. Figma の `figma-use` スキル

## 前段(準備①の残り、先に済ませる)
- **レイアウトマスク**: 表紙面(99×210mm)の外形・塗り足し域(上・右3mm)・文字ゾーン(K2 では下情報域=表紙面の下40〜45%)・CTA ゾーンだけを白/灰の矩形で描いた幾何図形 PNG を系統共通で1枚(K2用)、任意で K1 用1枚。**テンプレや完成見本のスクショ・切り抜きは絶対に参照画像に使わない**(出所未記録のイラストを含むため)。生成物は `docs/library/masks/`
- `素材` ページの直下にグループ `ライブラリ/<系統>/`(基底案)と `案件/<案件名>/`(地域モチーフ)を作る構成を決め、既存5グループと衝突しない名前にする(実施は投入時)

## 作るもの(v0)
- 基底案: K2 向け × 描法2(手描きの温かみ / フラットで明快)× 4系統(あいとま / 那智勝浦 / 登別 / MITT)= 8点。**背景と前景を分けて生成**
  - 背景 = 空・稜線・道・汎用の里山または街並み。人物・車両・地域固有の名所・文字を描かない。地平線帯(上端から約60%)は単純な稜線にして、後から `#地域モチーフ` で覆える余地を残す。色帯域は系統のパレット(colors.md)に従う。那智勝浦系は寒色可、MITT系はブランド色固定
  - 前景 = 顔のある人物1体以上(70代中心と家族、電話をかける/乗車する姿、記号化しない)と乗合タクシー(白いワゴン、右ハンドル・左側通行)を単色背景(#00FF00、パレットに近い色相なら #FF00FF)で生成 → キー抜き+エッジ収縮で実 alpha の PNG に
  - 比率: K2 ヒーロー枠+塗り足し ≈ **102:125(やや縦長)**。K1 は後日(102:213)
  - 採用後は同方向で 4K・文字なしのマスターを再生成(長辺 ≤ 4096px。Figma は超えると自動縮小)。2K は比較用
- 切り出し素材(人物・車両)は各系統2点以上
- 地域モチーフ(くらぶち): 榛名山など実在の山・名所のシルエット/簡略画、不透明、hero_horizon 帯に置く前提の横長
- tone.json 最小版(基底案ごと): `docs/plan/plan-v5.1.md` 6.2 のスキーマから meta(sheet/faces/fold)、direction、composition(K2_top_visual、hero.bleed_sides ["top","right"])、palette.roles(正規化規則を適用: main は白と 4.5:1、cta は 7:1)、typography.headline(許可リスト内。`M PLUS Rounded 1c` は Figma 名 `Rounded Mplus 1c`)、illustration.subjects、provenance。値は画像に見えるものだけ書き、見えないものは provenance=default
- 台帳: 生成物1点ごとに モデル名・経路・日時・プロンプト・採否 を `docs/library/ledger.csv`

## プロンプト構造(5.1 のとおり)
1. 役割: 地域交通の高齢者向けパンフレットを手がけるアートディレクター 2. 案件(基底案では地域名を渡さない) 3. 必須要素(上記の背景/前景) 4. 因子(構図・描法) 5. 制約(比率、文字なし、写実禁止、3Dレンダ調禁止、ロゴ・看板・偽QR・電話番号らしき数字禁止、着物・杖・白髪だけの記号化禁止、富士山+桜+鳥居禁止、紫→青グラデ禁止) 6. 参照(レイアウトマスク・系統の色チップのみ) 7. 出力 2K PNG → 採用後 4K

## 投入(Figma、モードD)
- `upload_assets`(currentPageId=素材ページ)→ 返ってきた URL に curl で POST → use_figma でライブラリグループへ移動・番号ラベル・`#tone` 同梱(基底案ごとの非表示 TEXT、Noto Sans JP Regular)
- 各素材の imageHash・px 寸法・配置想定を `docs/library/library-v0.json` に記録(P13 の dpi 計算と、スキルの clone 元 id に使う)
- 検討用の透かし付き画像は `#案_透かし有` グループに隔離(制作物には使わない)

## 禁止・注意
- ソコスト/unDraw 等のフリー素材、テンプレ内の既存イラスト、完成見本・参照ページのスクショを生成 AI の参照に渡さない(ライセンス違反)
- Gemini アプリ(無料/AI Pro)の出力は透かし付きで配布不可。必ず API(有料枠)
- API キー・課金情報をリポジトリに入れない。プロンプトと結果は台帳へ
