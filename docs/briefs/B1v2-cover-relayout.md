# 指示書 B.1 v2: 表紙面を K2 用に組み直す

## 目的

B.1 は既存の表紙構成(色背景+白パネル+中央ロゴ)の上にヒーロー枠を差し込んだだけだったため、H(a) 先行版で破綻した(`docs/reports/Ha-draft1-findings.md`)。表紙面(表1、右上の1面 563.7×1196px)を **K2(上にビジュアル、下に情報)として成立するように組み直す**。まず あいとま系1系統でレイアウト案を 2〜3 案出して Hiro が選び、決まった構成を残り3系統に展開する。

## 変えてよいもの・変えないもの

- **変えてよい(表紙面の中だけ)**: ヒーロー枠の位置・幅・高さ(表紙面の 50〜65% の範囲)、白パネル(`装飾:表紙背景` の背景2)の有無と形、タイトル・サブコピー・ロゴの位置と大きさ、CTA ブロックの位置、注記・`#AI表記` の置き場所、人物・車両・地域モチーフの配置規則
- **変えない**: 表紙フレームの寸法・折り線・塗り足し、表紙面以外の5面、本文と注記の書体・サイズ(12pt/9pt の下限)、電話番号のサイズ、QR のサイズ、`#` 命名規約、中面
- ヒーローの比率を変える場合、ライブラリ素材は CROP で合わせる。比率が 0.7〜0.95 の外に出て素材の作り直しが必要になるなら、案を出す段階でそう明記する

## レイアウト案の出発点(これに縛られず、良い案があれば出す)

| 案 | 骨子 |
|---|---|
| A 全幅ヒーロー+全幅情報帯 | ヒーローは裁ち落としの全幅。白パネルをやめ、下の情報域も全幅の帯にして端を揃える。タイトルはヒーロー上端のベタ帯または空の部分、ロゴは小さくして情報帯の上端へ |
| B パネル内ヒーロー | 白パネルを残し、ヒーローをパネル幅(488px)に収める(裁ち落としなし)。パネル上部にタイトルとロゴ、その下にヒーロー、下に CTA |
| C 絵の空にタイトル | ヒーローを大きく取り、空の部分にタイトルを白フチ付きで直接載せる。ロゴはタイトル横に小さく。人物と車両は中央寄りで向き合わせ、場面として成立させる |

どの案でも満たすこと: ロゴ・タイトル・注記・`#AI表記` の相互の重なり 0、ヒーローと下の情報域の左右端が揃う、中央に意味のない空白を作らない、人物の顔と車両が隠れない、人物が表1ビジュアルの 1/3 以上(R1)、電話番号と CTA は下情報域で読める。

## 作業

作業場所は作業用ページ「テンプレ改修_作業」(2053:2)。テンプレート 0:1・参照・制作物・素材ライブラリの原本は clone して使い、編集しない。

1. **あいとま系で案を組む**: 2053:3 を案の数だけ clone し、くらぶちの実際の文言(制作物 71:2 を読むだけ)と実素材(`ライブラリ/あいとま系` 2074:3、`案件/くらぶち` 2068:16)を入れた状態で各案を組む。灰色のプレースホルダだけの状態では見せない
2. 各案に preflight を実行し、表紙面の正立スクショ(180° 回転して保存)と改修前(71:2)を並べた比較画像を `docs/reports/B1v2-shots/` に保存
3. **ここで止めて Hiro に案を見せる**。各案の狙い・長所・懸念を短く添える。選ばれた案(または直しの指示)で詰める
4. 決まった構成を那智勝浦 2053:334・登別 2053:682・MITT 2053:1002 に展開。系統ごとに実素材+ダミー文言で合成して確認(MITT は下段正立、ロゴ類が多い点に注意)。4 系統のスクショを見せて Hiro の OK を得る
5. **差し替え**(OK 後): テンプレートページの表紙4系統を v2 に置き換え、現行 B.1 版は退避ページ「テンプレ旧_20260927」へ移す。`#config` は据え置き
6. 記録を更新: `docs/prep/template-refit-inventory.json`、`skill/references/template-and-assets.md` の id 表(D 前半で書いた現行 id を v2 に)、`docs/library/library-v0.json` の layout_rule(人物・車両の配置規則が変わった場合)、`docs/decisions.md`、`docs/tasks.md`
